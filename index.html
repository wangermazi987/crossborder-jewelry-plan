01

结论先行

市场大不等于容易卖；这个方案优先看需求空间与大陆团队的启动门槛。

首发市场：美国

仿饰品进口规模领先，零售电商体量大，女性在 Instagram、TikTok 的使用率为可视化内容提供了受众基础。竞争也最激烈，所以只测一个英雄产品。

首发渠道：Amazon + 内容

Amazon 允许个人卖家注册，不必先成立 LLC；但珠宝推荐费高。短视频负责展示设计和实物，Amazon 负责初期交易与交付体验。

独立站：先轻后全

中国大陆商户不能使用 Shopify Payments，需配置第三方支付。先确认账户与结账可用，再付费搭完整站；独立站不能替代获客。

关键判断：用原创设计而非品牌替代品的逻辑竞争。建立一个能讲清楚“造型来源、佩戴体验、材料规格、交付与售后”的品牌理由；如果产品只靠像某个奢侈品牌来吸引点击，建议停止并重新设计。

03

产品与品牌定位

从“某个品牌的平替”转为一个有自有识别度的原创设计商品。

定位假设

面向日常佩戴与送礼的原创设计珠宝：用独立造型、可靠佩戴体验和清楚的材质说明，提供“设计感明显、日常容易搭”的理由。首发受众先测试 25–44 岁、会购买配饰的美国女性；年龄范围是研究假设，不是已证实画像。

原创设计方向

建议把首款做成一条非对称折线 / 水流弧面结构的雕塑感手链：只有一个自有主造型，重点呈现曲面、留白与腕间比例。方向只是设计 brief，需由设计师重新绘制、打样和做原创性检索。

设计评审时检查整体轮廓、重复单元、连接方式、比例、表面纹理、扣件与包装。不要围绕其他品牌的专属名称、标识、经典图形或整体观感来做设计与营销。

首发 SKU 假设
1 款 × 2 色

先做一个原创手链，金色与银色两个表面处理。确认样品、材料和交付稳定后再增加耳饰或叠戴组合。

试价区间：$69–$89
仅作为愿付价格测试范围。最终价格由样品成本、检测、履约、平台费、退货和可承受获客成本倒推。

材料路线 A｜轻量试水

不锈钢基材 + 经供应商证明的表面处理，先验证耐磨、变色、扣件和佩戴舒适度。不要未经测试就承诺“防水、永不褪色、抗敏”。

材料路线 B｜提高客单

925 银或更高等级材料，需重新核算原料、镀层厚度、检测和小批量成本。确认需求后再走，不为了抬价先增加复杂度。

出货前检验

检查重量、尺寸、闭合牢度、边缘刮手、镀层均匀、色差、佩戴后摩擦表现和包装运输损伤。留存真实规格与供应商批次。

品牌承诺只保留三件事

原创造型：由你们解释它从哪里来→真实材质：规格和检测能对上→可靠体验：尺寸、发货、退换说清楚

06

独立站、落地页与客户承接

前期一页讲透一款商品；有订单证据后，再扩成完整品牌站。

第一阶段：轻量验证页

一屏品牌介绍 + 真实产品渲染 / 样品图 + 邮件登记 + 预计发售时间。清楚告知这是意向登记，不收款、不制造虚假库存紧张。

第二阶段：可交易独立站

首页、手链系列、商品详情、设计故事、材料与保养、发货与退换、FAQ、联系页。核心语言先用英文，先服务一个国家。

商品落地页建议顺序

产品佩戴主图 + 明确标题→价格 / 颜色 / 尺寸 / CTA→实物近景与 360° 短片→材料、重量和佩戴说明→发货、退货、FAQ 与评价

图片清单

手腕正侧面、不同肤色实戴、闭合方式、边缘和镀层近景、尺寸参照、包装与开箱、叠戴场景。真实产品为准，不能用 AI 把造型或材质修成未交付的样子。

文案信息

设计由来、具体材料、尺寸范围、重量、表面处理、保养方式、包装内容、生产地、出库时效、运费和退换。每一条承诺都要有依据。

转化信任

早期没有顾客评价时就展示创作过程、样品迭代和检验细节；收到授权后再上真实顾客照片。客服邮箱、常见问题、退款和订单追踪要容易找到。

两人客服流程

自动化：下单确认、发货与追踪、保养说明、常见问题模板。AI 可先草拟多语言回复与归类订单问题。

人工确认：退款、丢件、皮肤不适、商品质量投诉、支付争议和任何超出政策的承诺由人处理。AI 回复不能替代核实订单与实物情况。

$79 售价的费用示例（美元，未包含其他成本）

Amazon 个人计划：$79 × 20% + $0.99 = $16.79，约为售价 21.3%。Shopify Basic + PayPal 国际收款：$79 × (4.4% + 2%) + $0.30 = $5.36，约为售价 6.8%，另加月费、可能的汇兑、运费、退款和获客成本。这个比较不代表独立站更容易卖；Amazon 有平台需求，独立站需要自己带来顾客。

每单贡献毛利公式

可用于广告的单笔空间 = 实收商品收入 − 制造与包装 − 国际头程 / 本地履约 − 平台及支付费 − 运费补贴 − 退款损耗预留 − 税费

先用真实报价填完公式，再定义“最大获客成本”。当自然流量还没有收藏、询盘或订单信号时，付费广告预算保持为零；出现稳定转化后再做金额封顶的小测试。

PayPal 的 RMB 结汇费、Shopify 网关支持情况和平台费可能变化。PayPal 当前有阶段性结汇优惠，财务模型按常规收费测算，不把短期优惠算成长期利润。

08

90 天执行安排

每个阶段有输出和继续条件；预算与产品 MOQ 明确前，不扩大库存。

第 1–2 周

确定产品假设

访谈目标买家；分析 10 个原创珠宝竞品；画 3 个完全原创概念；询价至少 3 家供应商。

第 3–4 周

打样与验证

选 1–2 个样品方案；检验尺寸、舒适度、镀层和扣件；完成轻量落地页与首轮内容；收集真实反馈和邮件意向。

第 5–8 周

小批量上线

只在单品经济账通过、平台账户完成审核、履约时效可兑现后订首批货；先上线 Amazon；同一时间发布短视频并回复客户。

第 9–12 周

复盘与扩张门槛

复盘转化、贡献毛利、退货与售后原因；决定继续、改款或停止。通过后再开完整 Shopify 结账、试创作者合作和小额广告。

每周固定节奏

周一：看数据

订单、访问、加购、转化、流量来源、毛利、退货和客服问题。

周中：做内容

拍 2–3 条短视频：设计过程、真实上手、规格 / 尺寸 / 保养答疑；跨平台复用。

周末：作决定

保留一个有效主题，修改一个低效环节，记录支出和下一周要验证的问题。

继续 / 调整 / 停止门槛

  • 继续：买家能说清这款的购买理由；样品质量稳定；目标售价下订单贡献毛利为正；平台审核和履约方式已确认。
  • 调整：内容有人保存 / 点击但不购买，优先检查价格、商品解释、尺寸信任或运费呈现，先修一项再测。
  • 停止：差异化只能靠模仿其他品牌表达；扣除平台、物流与退货后无法留出获客空间；供应商无法稳定提供承诺规格；试错投入会超过你们设定的上限。

把创业过程沉淀成课程案例

课程素材从验证开始记，经营数据从真实订单来。

每个决策记录 7 项

日期与目标、原始假设、数据来源、AI 提示词与输出、人工核验和修改、实际成本、结果与下一步。

课程模块顺序

市场判断 → 原创产品 brief → 样品与供应链 → 商品图与落地页 → 账号与获客 → 收款及订单 → 客服与退货 → 单位经济模型 → 复盘与扩张。

课程可信度来自“全过程记录”。保存原始样品、供应商报价、内容版本、广告收据、订单和售后数据；公开课程前隐去客户与供应商隐私，并把失败实验完整纳入案例。

分工建议：一人负责产品与供应商验证；另一人负责客户反馈、内容拍摄和订单 / 售后记录；两人每周共同做去留决定。Codex 负责资料整理、文案初稿、页面原型、FAQ 和复盘摘要，所有材料与承诺由你们核对。
